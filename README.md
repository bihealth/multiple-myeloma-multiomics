## code repository for "Translating multi-omics complexity into sparse prognostic biomarkers for multiple myeloma"

this repo contains R and python scripts to carry out the re-analysis of the multi-omic multiple myeloma dataset of Ramberger et al.

## required inputs

- supplementary tables of [Ramberger et al.](https://www.nature.com/articles/s43018-024-00784-3)
- additional cohort annotation (here in `data`)
- Tables 1 and S4 from [Skerget et al.](https://www.nature.com/articles/s41588-024-01853-0) as well as the clinical data (available from [GDC](https://gdc.cancer.gov/))
- clinical data for [Shi et al.](https://www.nature.com/articles/nbt.1665) available from [GEO](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE24080)
